One system, two implementations

The SPA grew two parallel token sets plus a duplicate. They mostly agree on color because both build on the same brand primitives — but they name everything twice, and only one has a designed dark theme. That split is why a filter popover and a dropdown can feel like different apps.

The decision. New code uses one semantic vocabulary (section 2). The .mw set is the dark reference; the classic :root set grows dark values, not the reverse. Mono is for code and data only. A fixed type scale replaces the 26 ad-hoc sizes shipping today.

01

Type

Three registers, one job each. The one rule that fixes the "different app" feeling: DM Mono is for code and data only — CQL, counts, OIDs, versions. Anything a person reads as a word (a button, a tab, a dropdown's value) is DM Sans. Uppercase micro-labels may stay mono as an eyebrow — that's the one sanctioned chrome use.

Accent is spent once per view. Lava marks the single most important thing — the live pin, the primary CTA, the active bar — and nothing else. Semantic colors encode population/prediction/validation state, never decoration, and never count as the accent. When you need a calm second color, use info (blue).

Compute pill
CY 2025 +2 ▾

Reusable selector pill (PillMenu): status dot · value · +n · chevron, on the shared toolbar control surface (no resting fill + hairline + 9px). Its value is the first execution parameter — what must be legible without opening anything, because every number on the page is scoped to it; the earlier icon-only variant (dot + chevron, no text) is retired, a wordless trigger made the pill's whole state a tooltip. A trigger prints one value and counts the rest: printing them all makes a toolbar control that resizes with whatever measure is open. Opens a three-group popover — Data Source and Updates as single-select rows, then Parameters last, one ‹ value › stepper row per parameter (a parameter is a value on an ordered domain: the arrows say which way is "more" and are disabled at its ends, and stepping does not close the pill). The dot is gray at rest and accent once a data source engages compute; it does not animate. Open state is a straight accent bar.
